# Volleyball Analytics Capstone

## Project Overview
This project explores how volleyball performance metrics can be used to predict match success and support strategic decision-making through data analytics.

## Research Questions
- Which volleyball metrics best predict winning?
- How does serve efficiency impact match outcomes?
- Which performance indicators correlate most strongly with offensive success?

## Tools Used
- Python
- Pandas
- SQL
- Tableau / Power BI
- Scikit-learn
- Jupyter Notebooks

## Planned Features
- Data cleaning pipeline
- Exploratory data analysis
- Match performance dashboards
- Predictive modeling
- Strategic coaching insights
