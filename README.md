# Volleyball Analytics Capstone

## Project Overview
This project explores how volleyball performance metrics can be used to identify performance trends, evaluate player efficiency, and predict match success through data analytics.

The project uses NCAA women’s volleyball statistics to analyze offensive efficiency, player production, match outcomes, and statistical relationships between key volleyball metrics.

---

## Research Questions

- Which volleyball metrics are most strongly associated with winning?
- How does hitting percentage influence match outcomes?
- Which player positions demonstrate the highest offensive efficiency?
- What statistical relationships exist between offensive and defensive metrics?

---

## Key Early Findings

- Winning performances show substantially higher hitting percentages than losses.
- Middle blockers and setters demonstrate the highest offensive efficiency.
- Offensive efficiency appears strongly related to match success.
- Attack volume increases both kills and offensive errors.
